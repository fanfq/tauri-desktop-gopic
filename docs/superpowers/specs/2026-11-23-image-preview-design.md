# 图床图片预览优化

范围：Tauri 桌面版。根据本轮确认优化自适应显示、放大后拖拽、双击复位和加载重试；保留复制链接与 Escape 关闭。

根因：原实现将已 contain 的图片通过 transform 居中放大，overflow-auto 无法访问负方向的溢出区域，且百分比不对应原图像素。另一个确认问题是 `.page-content > *` 的 1180px 最大宽度覆盖了弹窗在小窗口中的最大宽度。

实现：独立 ImagePreview 组件使用原图尺寸、容器尺寸和受限平移量计算显示。首次与窗口调整时居中适应，默认不放大小图；100% 对应原图 CSS 像素。按钮及滚轮缩放，放大后指针拖拽，双击适应窗口。弹窗内部固定标题与工具栏，图片画布占据剩余空间。

状态：加载中、加载失败可重试、缓存缺失；只重载当前缓存地址，不请求云端。不修改上传、删除或缓存生命周期。

验证：缩放锚点、拖拽边界、长图/宽图/小图及零尺寸单测；前端构建、格式检查；浏览器验证布局与交互。原生构建独立记录，不将浏览器演示视作真实缓存协议验证。
