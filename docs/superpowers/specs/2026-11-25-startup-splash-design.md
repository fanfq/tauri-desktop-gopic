# GoPic 冷启动过渡设计

用户已批准窗口内 Splash 方案，并授权直接实施，不自动 commit。

入口 HTML 在 React 加载前显示纯色背景、现有 `/gopic.png` 和 GoPic 品牌名，图标轻微呼吸。主界面保持挂载在遮罩后，禁止提前交互。原生配置成功读取、主题应用、字体与品牌图片就绪，并经过两次动画帧后，遮罩用 250ms 淡出，再移除并恢复主界面交互。没有人为最短展示时间。

原生初始化失败也触发退场，露出现有错误和重试按钮。后续配置刷新、页面切换、托盘恢复均不重新创建遮罩。浏览器预览在首次挂载后使用同一过渡。减少动态效果模式关闭呼吸和淡出。初始背景跟随系统主题，退出前对齐已保存的应用主题。

验证覆盖资源就绪等待、双帧、StrictMode 清理、动画结束与超时移除、减少动态效果，以及现有测试、构建、格式检查。浏览器验证与原生冷启动验收分别报告。
