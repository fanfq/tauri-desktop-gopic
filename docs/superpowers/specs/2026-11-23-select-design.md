# 统一下拉选择框

用户已确认：仅修改 Tauri 工程全部六处选择器，保留业务保存、筛选及预览边界。不自动 commit。

使用共享受控 Select 组件替代系统 select：普通、紧凑及云服务双行三种触发器共用菜单，沿用主题变量、细边框、蓝色选中态和 6–8px 圆角。选项长文本省略并提供 title，菜单滚动，视口不足时向上展开。菜单挂在当前 .app 下，继承深浅主题，并避免内容滚动容器裁切。

支持方向键、Home/End、Enter/Space、文字查找、Escape、Tab、外部点击关闭、禁用和空选项。取消不修改受控值，选择后焦点留在触发器。窗口缩放/滚动关闭菜单，避免定位漂移。

验证：现有测试、边界定位测试、TypeScript/Vite 构建、格式检查及浏览器页面交互。浏览器验证不代表原生 WebView 或云端服务实测。
