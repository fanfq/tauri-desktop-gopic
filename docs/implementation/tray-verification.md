# macOS 托盘实现与验证

参考 Flutter 的 `macos/Runner/StatusBarController.swift` 与 `AppDelegate.swift`，保留用户新增的任意文件上传要求。

## 已实现

- 直接复用 Flutter assets/icon.png，18px 彩色非模板图标；蓝色上传、绿色成功、红色失败，完成后 3 秒恢复。最近上传复制后 2 秒恢复。
- 左右键 mouseUp 弹出原生菜单：最近上传（URL 提示、点击复制）、打开 GoPic、退出 GoPic。空记录禁用。菜单使用 Cocoa popUp，避免同步菜单循环持有 tray-icon 内部借用。
- 280×132 非激活浮层，14px 圆角、阴影、拖入高亮；距按钮 8px 并限制屏幕边界。离开后延迟 0.45 秒隐藏，允许移动至浮层。
- 文件拖放复用 Rust 上传管线、启用配置、图片压缩与自动复制；拒绝目录，支持普通文件与无扩展名文件。
- 关闭窗口/普通退出转后台；托盘显式退出结束进程，打开操作恢复主窗口与 Dock。
- 并发批次全部完成前保持上传状态；版本号在主线程绘制前再次校验，避免旧反馈覆盖新上传。剪贴板失败独立报告。

## 验证边界

状态机测试覆盖旧恢复计时、已经排队的旧绘制、并发批次、上传期间复制及跨批次剪贴板失败。Rust 编译会同时编译 Objective-C bridge。前端测试、构建与格式检查独立执行。

隔离的 GoPic Tray Check 应用已启动，页面加载正常。自动化无法访问系统状态栏菜单表面（SystemUIServer 接口超时），因此未声称实际左右键菜单、拖放手势、浮层跨屏定位或关闭/重开行为已通过 UI 验收。尚需在 macOS 菜单栏手动验收上述行为；真实云上传和登录自启动也不属于本地协议测试的证明范围。
