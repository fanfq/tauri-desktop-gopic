## 当前流程审查

1. 上传：入口清楚，但压缩栏优先于主任务占据首屏；标题、副标题、全局预览条和页脚重复解释。见 01-current-upload.jpg。
2. 图床：图片可浏览，常驻选择框、卡片边框、格式角标、顶部辅助信息竞争注意力；可将主要动作聚焦复制，其他动作在悬停或选中时展开。见 02-current-gallery.jpg。
3. 云配置：导航厂商、配置列表和表单三层并列，窄窗口挤压明显；建议整合为设置内的云配置列表，新增时选择厂商，编辑时显示表单。见 03-current-cloud.jpg。
4. 配置：单页多组面板向下延伸，低频清理/迁移与高频命名没有足够层次；建议设置内分为云服务、上传规则、通用与数据。见 04-current-settings.jpg。

辅助文字字号偏小、颜色较淡存在可读性风险；本次未做完整对比度与屏幕阅读器审计。

## 共用信息架构建议

- 日常工作区聚焦上传、浏览图片、复制链接。
- 当前云配置可切换；管理配置放入选择器末尾及设置。
- 所有五个厂商、多配置、压缩、命名、导入导出、缓存和自启动保留。
- 将“云服务”和“配置”合并到设置，避免厂商占据主导航。
- 压缩/命名为上传规则；仅显示简短摘要，点击展开，配置一次后持续生效。
- 图片选中后出现批量操作；危险操作进入更多菜单并确认。
- 去掉口号式副标题、长期帮助文案和常驻演示工具条；演示能力移入独立菜单，保留预览边界提示。
